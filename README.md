# Сплавы

CRM для организаторов сплавов на байдарках.

- Календарь выездов, заявки, списки участников и лист ожидания.
- Учёт предоплат, оплат и возвратов.
- Распределение участников по байдаркам, транспорту и домикам.
- Назначение инструкторов и планирование смен сотрудников.

Приложение работает без интернета и синхронизирует изменения при подключении. Интерфейс написан на Flutter, локальные данные хранятся в SQLite, сервер работает на Supabase.
